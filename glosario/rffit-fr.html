RFFIT vs FAVN : pourquoi le mauvais test invalide l'exportation

⚠ Alerte réglementaire · 11 juillet 2026

Le Japon a révoqué un laboratoire ; le CDC le maintient approuvé. L'AQS a retiré Biobest Laboratories de sa liste de laboratoires désignés pour violation des normes. Le RFFIT est un test de neutralisation des anticorps antirabiques. Il mesure techniquement la même chose que le FAVN, mais N'est PAS accepté par l'UE, le Japon ni l'Australie pour l'exportation d'animaux.

Définition rapide

RFFIT ≠ FAVN · No válido UE · No válido Japón · No válido Australia

Le RFFIT (Rapid Fluorescent Focus Inhibition Test) est une technique de laboratoire qui mesure la capacité neutralisante des anticorps antirabiques dans le sérum animal. Il mesure techniquement le même paramètre que le FAVN (≥ 0,5 UI/mL) mais utilise une méthodologie différente. Le problème réglementaire est que l'Union européenne, le Japon, l'Australie et la Nouvelle-Zélande exigent spécifiquement le FAVN comme méthode acceptée. Un résultat RFFIT, même positif, n'est pas interchangeable avec un résultat FAVN pour ces destinations.

Définition technique formelle

Les deux tests (RFFIT et FAVN) sont des techniques de séroneutralisation en culture cellulaire. Le RFFIT utilise l'immunofluorescence pour détecter les foyers d'infection virale inhibés, tandis que le FAVN utilise des anticorps fluorescents pour marquer le virus vivant. Les deux expriment le résultat en UI/mL sur la même échelle de référence OMS. La différence est méthodologique et de validation réglementaire : l'OIE/OMSA, l'UE (Rèl. 576/2013 Annexe IV) et l'AQS japonais spécifient explicitement le FAVN. Le RFFIT est largement utilisé aux États-Unis par le CDC pour l'évaluation humaine et certains protocoles internes de l'USDA-APHIS, ce qui crée de la confusion : aux États-Unis, il peut être accepté dans certains contextes, mais pour l'exportation depuis le Pérou vers l'UE, le Japon ou l'Australie, le RFFIT n'est pas valide.

Contexte réglementaire à l'exportation

L'erreur de demander un RFFIT au lieu d'un FAVN est l'une des plus coûteuses dans l'exportation d'animaux depuis le Pérou. Si le propriétaire contacte un laboratoire local ou étranger qui effectue le RFFIT (et non le FAVN), le résultat n'est pas accepté dans l'UE ni au Japon, et le processus doit être répété depuis le prélèvement sanguin, impliquant des mois d'attente supplémentaires. Depuis le Pérou, le laboratoire accepté internationalement pour le FAVN est le KSVDL (Kansas State Veterinary Diagnostic Laboratory), certifié OIE/OMSA. Certains laboratoires américains proposent les deux tests (RFFIT et FAVN) ; il est essentiel de spécifier explicitement FAVN dans la demande.

Chronologie typique depuis le Pérou

  • Vérifier quel test le pays de destination exigeAvant tout prélèvement sanguin : confirmer avec la réglementation du pays de destination. UE, Japon, Australie, NZ → FAVN obligatoire.
  • Spécifier FAVN explicitementLors de l'envoi de l'échantillon au KSVDL ou à un autre laboratoire certifié, indiquer « FAVN » dans la demande. Ne jamais supposer que c'est automatique.
  • Vérifier l'en-tête du rapportLe rapport doit indiquer « FAVN » ou « Fluorescent Antibody Virus Neutralization ». S'il indique « RFFIT » ou « VNT », il n'est pas valide pour l'UE/le Japon/l'Australie.
  • Recommencer le prélèvementSi un RFFIT a été obtenu à la place d'un FAVN, le prélèvement sanguin doit être répété et un nouveau résultat attendu. Il n'existe aucun moyen de « convertir » un RFFIT en FAVN.

Erreurs fréquentes

  • Supposer que RFFIT et FAVN sont équivalents pour tous les pays. Ils mesurent techniquement la même chose, mais ne sont pas interchangeables sur le plan réglementaire. L'UE, le Japon, l'Australie et la NZ n'acceptent que le FAVN.
  • Ne pas vérifier le type de test sur le rapport de laboratoire. Certains laboratoires émettent des rapports avec une terminologie générique. Toujours demander que le rapport précise explicitement « FAVN ».
  • Utiliser le RFFIT parce qu'il est moins cher ou plus rapide. Le RFFIT peut être moins coûteux dans certains laboratoires, mais si la destination ne l'accepte pas, l'économie se transforme en perte totale du temps et du coût du processus.
  • Faire confiance au vétérinaire local pour connaître la différence. Tous les vétérinaires ne connaissent pas la distinction réglementaire entre RFFIT et FAVN. Il est de la responsabilité du propriétaire de vérifier auprès de la destination avant le prélèvement.

Questions fréquentes

Quelle est la différence technique entre le RFFIT et le FAVN ?
Les deux sont des tests de séroneutralisation : ils mesurent le nombre d'anticorps que le sérum de l'animal possède pour neutraliser le virus de la rage. La différence réside dans la méthode de détection : le FAVN utilise le virus complet fluorescent marqué directement, tandis que le RFFIT détecte l'inhibition des foyers d'infection dans les cellules. Les deux expriment le résultat en UI/mL. Le choix entre l'un et l'autre est, en pratique, une question de ce qu'accepte le régulateur du pays de destination.
Pourquoi tous les pays n'exigent-ils pas le FAVN si le RFFIT mesure la même chose ?
C'est une question historique et de validation officielle. L'OIE/OMSA a validé le FAVN comme méthode de référence pour le commerce international des animaux. Les pays qui ont adopté cette norme (UE, Japon, Australie) exigent le FAVN. Les États-Unis ont leur propre cadre réglementaire pour usage interne où le RFFIT est traditionnel. Lors de l'exportation depuis le Pérou vers toute destination suivant la norme OIE, le FAVN est obligatoire.
Si j'ai un résultat RFFIT positif, puis-je l'utiliser pour quelque chose ?
Cela dépend de la destination. Pour les États-Unis continentaux avec certains programmes USDA, il peut être valide dans certains contextes. Pour l'UE, le Japon, l'Australie et la NZ, il n'est pas valide et le processus doit être répété avec le FAVN. Avant de supposer qu'il est utile, vérifier auprès de l'autorité de destination.
Le KSVDL effectue-t-il le RFFIT ou le FAVN ?
Le KSVDL (Kansas State Veterinary Diagnostic Laboratory) effectue le FAVN, qui est la méthode certifiée OIE/OMSA exigée par l'UE, le Japon et l'Australie. C'est pourquoi le KSVDL est le laboratoire de référence depuis le Pérou : il est certifié OIE pour la bonne méthode.
Puis-je demander à un laboratoire local au Pérou de réaliser le FAVN ?
Il n'existe pas de laboratoire certifié OIE/OMSA au Pérou pour le FAVN. L'échantillon doit être envoyé à l'étranger, le KSVDL étant le laboratoire de référence. Tout résultat d'un laboratoire non certifié OIE, quelle que soit la méthode, n'est pas accepté internationalement.
